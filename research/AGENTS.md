# 研究接口的调用约定

先读 `README.md`，然后运行 `python -B -m reproduction.research_env_v1 status --json`，以当前哈希和验收记录确认环境。

本版本研究对象是 `registry.json` 指定的离线比较分配/早停模块。实验策略写入 `research/policies/` 的新文件，保留 `example_random.py` 作为已验收参考。可信 host、标签、反馈、预算、固定汇总器和评分规则由 `protected_manifest.json` 绑定；改变研究口径先登记新的环境版本。

执行研究实验前先给出方案卡：baseline 问题、原始文献及对应机制、机制如何配合、可检验假设、允许修改的模块、最小实验、控制/消融、支持/削弱假设的结果、预算和停止规则。先完成方案审阅，再使用统一 CLI 执行对应实验。每次使用新输出目录，保留失败和负面结果。

本版本 `--limit-jobs` 是接口短测；完整开发评测使用全部 850 场。26 任务属于开发集。研究代理的自身代码生成工作区隔离、跨运行资源总额、具体 AI Scientist 版本适配及新任务/在线评测另行验收。
