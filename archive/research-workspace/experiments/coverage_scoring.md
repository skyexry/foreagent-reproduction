# Coverage 批次评分与记录口径

本说明在运行中补记，依据已经实际使用的代码与原始文件；不是运行前预注册。没有改变提示词、抽样、模型参数或已采用的判断。

## 抽样与标签

固定分母为 **246 对、26 个任务**，不是 260 对。每任务最多 10 对；dog-breed-identification 和 nomad2018-predict-transparent-conductors 各只有 3 对。使用作者 solutions_subset_50 的配对集合，每任务以 `random.Random(f'{20261021}:{task}').sample` 无放回抽样，保留原始候选顺序（A=0，B=1）。同一个候选允许参与多对；最终清单及出现次数见 pairs_manifest.json。

未额外按作者预测正确与否、模型输出或分差筛选。来源集合此前如何剔除训练失败等情况，未独立重建。本地检查缺失输入、标签方向和完全相同的分数，有问题则报错而不是静默删样本。全部来源配对没有完全相同分数；不设置近似平局阈值，分差很小仍按原分数比较。真实胜者由 is_lower_better 决定取较小或较大分数，并核对作者 best_index。任务指标原文、分数和标签单独保存在清单，不作为请求中的额外字段。

## 有效性、失败与重试

复用作者 parse_response：拼接 reasoning_content 与 content，解析 JSON；允许 predicted_ranking 首位回退，按作者实现用 int 规范化索引。再校验索引为 0/1 且 finish_reason 为 stop，才计为有效。有效结果的索引与真实胜者相同计 1，否则计 0。此口径不是人工根据自然语言理由重评分。

平局、不确定、无法解析、超时、接口错误、非正常结束不计为有效判断，也不计为正确；若文字说不确定但结构化字段给了有效索引，仍按现有解析器采用该索引。未能细分的错误保留 invalid_output，不事后猜测具体原因。保留原回答以供后续人工审计。原 prompt 已有可选 confidence；不新增要求，不从措辞推测置信度。

本批自动重试次数为 0；恢复运行只继续未派发的样本，不重试已结束的失败。每对目前只有 attempt-001，有效时采用该次，失败时没有采用结果。未来如另行授权重试，必须新增 attempt，保留原失败，另行明确结果采用规则与重试前后指标，不覆盖本批结果。费用统计包含所有已知用量的调用；失败调用未知费用标为未知。预算预留不是实际账单。思考 token 已包含在输出 token，不能重复计费。

## 汇总

令 N=246，V=有效判断数，C=正确判断数：

- 有效输出率 V/N。
- 有效判断准确率 C/V；V=0 时为 null。
- 全样本正确率 C/N；失败和未获得判断的样本都不记为正确。
- 另列已结束请求数、失败数、在途数、未派发数；运行中以上指标标为暂时值，不将未派发样本称为 API 失败。
- 主要汇总为按候选对计数的 micro；另报告每任务 C_t/N_t 及其在 26 个任务上的等权平均（macro）。有效样本 macro 如另报，需明确零有效任务如何处理，不与全样本 macro 混淆。
- 作者对照另算同一批有效且可匹配样本，并保留作者全部 246 对结果；这只是一次公开运行，不是论文三次均值。抽样权重不同，不能把本轮直接当作论文全量准确率的复现。

## 保存与缺失

本地 outputs/coverage-20261021/audit 下三个主文件：run_config.json、pairs_manifest.json、attempts.jsonl。code 子目录保存当前实现与完整 prompt 源码快照。原始 pair/request/pause 文件继续保留；输入固定文件位于 data/coverage，并有 SHA-256。API 密钥不写入这些记录。

导出器不调用 API，不改原始结果，逐一校验实际请求可以从固定输入重建、原始文件哈希、标签与计分一致性。JSONL 导出的是调用终态；在途与尚未派发的 ID 单独记在配置，结束后再次导出。模型输入与真实分数/标签分文件保存；原始遗留 pair 文件包含评分字段，因此不能直接作为未来模型输入。

未记录的准确墙钟开始/结束时间、失败正文/错误消息、响应头、SSE 原始帧及失败前部分文本写明缺失，不用文件时间或反推值冒充。API created 是服务端字段。早期非流式与单次流式验证的运行脚本快照没有保存，当前快照不冒充早期版本。所有 token 缺失为 null；汇总给出已知量和缺失调用数，不把缺失当 0。
