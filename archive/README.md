# 历史研究工作区

`research-workspace/` 保存归集前的研究仓库内容，包括早期 pairwise 脚本、原版离线复现与核验、历史 R6–R8 及旧报告。文件按原有相对布局整体归档，代码与已冻结结果保留原文。

当前 HW3 阅读入口位于仓库根 README 和 `phase1-reproduction/README.md`。历史目录中的阶段状态、路径和后续计划按记录当时的版本解释；当前状态以根 STATUS.md 为准。

旧基线核验从 `research-workspace/` 作为工作目录运行；相应数据按该目录的来源清单获取。原作者许可证同时位于当前第一阶段源码目录。历史发布标签 `baseline-reproduction-v1` 保留原提交。
