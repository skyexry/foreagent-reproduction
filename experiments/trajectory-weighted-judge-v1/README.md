# 静态裁判训练先导

**保留 C0。** 用一次错判对最终选优的损失给训练样本加权，相对等权训练的收益为 **0.00116**，95% 任务簇区间 **[−0.00232, 0.00448]**。事先规定的推进尺度为 0.01。分差加权与打乱权重的点估计也略好于终局加权。本轮固定表示的先导到此结束。[预登记](protocol.json) · [下一阶段方案卡](../../research/研究路线.md)

**试验设计。** 每折留出一个任务，用其余任务的执行胜者训练相同的线性裁判。训练任务权重来自固定 C0 赛程中同一比较的两个后续分支；推理阶段仅看任务、报告与代码。四臂均先封存胜者，再使用各自预测重走 C0 赛程。保留原归档的采纳条件、置信度和相同预算上限。损失是所选代码与池内最好代码的执行差距，按该池分数跨度归一；并列时均匀取期望。普通监督借鉴 ForeCritic 的标签与目标，本次冻结小编码器和线性头不同于作者 9B 裁判。[ForeCritic](https://arxiv.org/html/2610.38439v1) · [评测口径](evaluation/README.md)

**效果为什么小。** 17,877 个严格监督对中，只有 1,728 个获得正的终局权重增量。相对等权模型，终局加权在全部 18,224 对预测中改变了 171 个胜者，最终只改变原 DeepSeek 850 场中的 28 场选集，14 场改善、14 场变差。原门槛采纳且有严格执行胜者的 10,271 对上，原裁判/等权/终局加权的逐对正确率为 65.99%/50.78%/50.90%。三份 GPT 采纳条件下的合并收益为 −0.00063，95% 配对区间 [−0.00174, 0.00032]。较弱的表示、少量权重变化和旧赛程的状态分布都可能限制本次结果；该设计没有单独识别三者。[分叉与权重](credit/README.md) · [训练封存](train/README.md) · [结果与复跑](evaluation/README.md)

**范围与成本。** 全部 26 项为开发任务，425 池、850 场来自相同开发语料；GPT 归档是同任务上的另三份采纳记录。冻结 CodeT5-small 在 CPU 编码 877 份代码与 26 份任务上下文，耗时 130.9 秒，覆盖原代码 token 的 52.26% 和上下文的 17.66%。随后做 104 次实际线性拟合，耗时 17.1 秒。共完成 17,000 份离线选择，3,400 份 C0 原轨迹复现，72,896 条逐臂预测经独立回算。区间以固定的留任务预测为条件；不同训练折共享任务。本轮沿用已有候选执行成绩，付费 API、GPU 租用和新增候选执行均为零。[CodeT5 原文](https://aclanthology.org/2021.emnlp-main.685/) · [固定权重](https://huggingface.co/Salesforce/codet5-small/tree/b1ee9570c289f21b5922b9c768a1ce12957bf968) · [编码收据](representation/run_1/receipt.json) · [评分摘要](evaluation/run_1/summary.json)
