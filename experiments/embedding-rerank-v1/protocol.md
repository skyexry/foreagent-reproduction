# Advisor ranking diagnostic and first embedding reranker

Registered before computing this experiment’s ranks, diagnostic or reranker results. The prior all-pairs Copeland top-1 diagnostic, TF–IDF memory pilot, weak CodeT5 linear classifier and 26-task development use were already known. Stage A reads the terminal displayed ordering of the actual corrected C0 tournament under its original budget. Stage B is a direct implementation of retrieval-based reranking using cached pretrained representations. Use 425 fixed pools, two seeds, primary archived DeepSeek judgments plus three pooled GPT replications. Within a task average seeds and pools before weighting tasks equally. No new judgments, training of candidates, or GPU.

A. Define fourth-or-lower as occupying position 4 or later (also report strict 5+ for the wording “after fourth”). Measure at least three strictly better-ranked candidates, plus expected 4+ position under a uniform permutation of a boundary tie. Report true first and true second separately, and probability both are lost. Resolve equal official scores uniformly over the true tied group. Exclude pools with fewer than four candidates from the 4+ decision denominator; report coverage and the attainable diagnostic-specific denominators. For a top-three shortlist, report expected normalized loss even with perfect final selection among the three. This isolates the score cost of discarding candidates. If DeepSeek has positive guaranteed 4+ misses on multiple tasks and shortlist loss above .01 task-macro, run Stage B. This is an operational pilot gate chosen here; the advisor did not prescribe its numerical value.

B. For each target task, retrieve only from the other 25 tasks. Exclude training code sharing bytes or an identical parsed Python syntax tree with any code in the target task. Compute a percentile from official execution scores within each reference task (higher always better; midrank ties). From each reference task take its nearest code by cosine of frozen 512-dimensional CodeT5-small embeddings, then average the percentiles of the three nearest of these examples. Fixed k=3, one neighbor per reference task. No labels of the target task enter its ranking. One change to C0: add the midrank of this retrieval score to the midrank of the C0 display groups with equal weight; best rank sum wins, exact ties are averaged. Score the same cached decisions fully, including agreements. Controls: C0 with identical trace, retrieval alone with zero pairwise judge reads, and the same fusion with reference scores shuffled within task (one prespecified negative control seed). Verify no target label lookup, stable top sets, all baseline traces/top sets, and cohort counts. Archive per-task results and episode-level selections. Main metric is normalized regret, secondary best-hit rate and diagnostic changes; .01 improvement and a positive lower bound on a paired 10,000-resample task interval in both DeepSeek and pooled GPT are required to recommend this variant. No hyperparameter search. Cross-judge agreement and leave-one-task-out evaluation on these already-viewed tasks are development evidence. The corpus supplies outcome labels only; no GRPO or critic-free policy training is implied.
