# 老师的 Top‑1/Top‑2 诊断与 embedding 排序先导

**基于作者已评分的 corpus，真实前两名经常被 C0 排到第 4 名及以后。用跨任务的 CodeT5 相似程序重排，平均选择质量下降。** 老师的原问题和各方向状态见[逐条答复](../../research/advisor-directions.md)。

沿用 425 个固定候选池、每池两个排程种子和最多 13 次裁判读取。重新调用原生 C0，导出**所有**显示名次组，并与已有 3,400 条轨迹分别核对终选集合、查询顺序、判断和预算。评分使用作者 corpus 的任务内真实执行结果，数据流与研究协议见[运行前登记](protocol.md)。

| 基线诊断 | DeepSeek | 三份 GPT 判断合并 |
|---|---:|---:|
| 真实第一落在第 4 名及以后 | 50.3% | 53.5% |
| 真实第二落在第 4 名及以后 | 66.8% | 62.4% |
| 真实前两名同时掉出前三 | 31.2% | 31.7% |
| 即使并列中先取该程序，真实第一 / 第二仍进不了前三 | 36.4% / 54.0% | 49.0% / 56.7% |
| 按“第 4 名以后”严格取第 5 名起，真实第一 / 第二落入该段 | 39.1% / 54.7% | 41.8% / 50.5% |
| 假设始终从前三中选到实测最好的一份，距全池最佳的归一化损失 | 0.0846 | 0.0996 |

排名按实际位置计数。显示名次并列时在组内均匀占位，真实成绩并列时也对相应名次对称处理。第四名可能出现的有 24 个任务、423 池、每份判断归档 846 场；其余两任务合计四场、每池三个候选。第 5 名统计在本批语料的可评集合相同。百分比是各任务等权的概率，两个种子及不同裁判归档不作为新的独立任务。完全弃权时，仅平局就可能产生排序下移，因此同时报告并列顺序都无法挽救的比例。

| 最终选一份代码，26 任务等权归一化损失（越低越好） | DeepSeek | GPT 合并 |
|---|---:|---:|
| 原预算 C0 | 0.2642 | 0.2725 |
| 纯跨任务 embedding 检索，无需成对裁判 | 0.3338 | 0.3338 |
| C0 显示名次与检索名次等权相加 | 0.2871 | 0.3115 |
| 相同融合规则，将参考分数在各参考任务内打乱 | 0.2872 | 0.3133 |

对每个目标任务仅从其余 25 个任务检索，排除与目标代码相同的语法树。用已有 512 维 CodeT5-small 向量，取三个不同参考任务各自最接近的代码，让它们在原任务中的相对成绩给新候选排序。比 C0 的收益在 DeepSeek 是 −0.0230，95% 任务重采样区间 [−0.1082, +0.0482]，GPT 为 −0.0391 [−0.0840, +0.0042]。无论用真实参考成绩还是打乱成绩，DeepSeek 上的点估计很接近。该版本未达到预登记门槛，保留 C0。编码只覆盖原始代码 token 的 52.26%，任务本身相异，这次对照不能单独分辨两者的贡献。

指标可从[逐场冻结选择](run-001/decisions.jsonl.gz)、[各任务结果](run-001/per_task.json)与[汇总](run-001/summary.json)重算。参考样例 ID 随[邻居记录](run-001/neighbors.json)给出。另见[同任务、裁判挑历史 vs 随机挑历史对照](history-control/protocol.md)。纯 CPU，本轮新增模型调用和候选训练均为零。相同 26 个任务是开发数据。

## 同任务参考及选择偏差

在同一任务内部，先把目标池整批留出，再向“裁判挑历史”和“随机挑历史”两组提供相同的历史代码对。每对只揭开一份真实分数；用三个相似历史样例的成绩辅助 C0 排序。21 个任务、802 场有至少三个可揭开的历史结果，其余回退 C0。五份固定抽样中每个判断归档共提供 35,730 对历史比较（计入重复出现），其中 584 对缺少已存判断，两组共用同一枚硬币。这是 corpus 上的单轮模拟。同任务参考来自其他代码，历史分数使用 corpus 测试成绩作代理。嵌入在两项实验中相同，但历史数、任务、筛选机制不同；不能将两个实验的差异全部归因于是否跨任务。

| 26 个开发任务，选择损失越低越好 | DeepSeek | GPT 合并 |
|---|---:|---:|
| C0 | 0.2642 | 0.2725 |
| 等量随机历史 + C0 | 0.2322 | 0.2339 |
| 裁判挑的历史 + C0 | 0.2250 | 0.2181 |

裁判挑历史相对 C0 的收益为 0.0392 [0.0050, 0.0829] 和 0.0544 [0.0195, 0.0936]；相对随机历史的收益为 0.0072 [−0.0022, 0.0163] 和 0.0158 [0.0065, 0.0267]。区间按任务重采样。单轮结果没有显示裁判挑历史导致整体成绩下降。当前检验尚未隔离所有同源近似程序，也没有模拟多轮裁判自选、自我强化。后续优先按原始生成运行整组隔离再测。完整[历史对照结果](history-control/results.json)。
