# 修正版原排序与新排序：本轮独立协议

正式输入为固定作者代码、原始Corpus及作者DeepSeek逐对反馈。R6–R8的协议、候选池、反馈附件、实现和实验结果均排除出本轮运行入口。

先构建共同C0修正版本：缓存身份/上下文、提交隔离、最佳节点绑定和独立评分。原淘汰赛、门槛、复赛和安全上限保留。新策略为“覆盖候选后，优先问可能改变最终选择的对局”。随机、覆盖后随机作为机制控制。

每任务最多20个新候选池，每池2个新seed；候选最多10个，最多13条新反馈。小任务按实际候选数和全部可比较对数计算预算。候选池按代码内容去重、排除非有限成绩，使用原反馈覆盖作准入；样本数和准入偏差完整报告。

主指标为每任务等权的归一化选择损失；报告均匀并列选择的最佳命中率、实际新判断、缓存读取与预算拒绝。真实成绩在所有方法作出选择后由评价器使用。

本轮26任务属于已查看开发材料；结果是离线冻结反馈下的探索性验证。主动策略是决策敏感启发式，正式论文新颖性与前瞻泛化另行检验。若结果负面或区间包含零，照实报告并保留原方法。

真实端到端、新LLM反馈、GPU实验使用独立预算与协议。本轮先完成CPU检查、短训练诊断和新的离线配对结果。
