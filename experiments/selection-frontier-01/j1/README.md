# J1｜完整随机补问赛程的方向纠正诊断

任务等权选择损失 **0.27678483 → 0.09814616**，潜在收益 **0.17863867**，95%任务簇区间 **[0.11544985, 0.26236971]**。任务等权最佳命中率 **20.9728% → 43.0369%**。全部26开发任务、425池、850场保留；场次改善549、持平228、恶化73。

**“完整”指原 `coverage_random` 臂问完预定预算后的全长稀疏赛程。** 每场原样保留 `min(13, n(n−1)/2)` 次唯一读取。840场含10个候选，每场保留13条已问边，候选对总数为45；纠正覆盖的范围始终是这13条已问边中的有效严格错向。小池沿用原来的完整可用预算。运行记录中“完整随机图”的具体含义以本段为准。

每臂沿用11004次逻辑读取：其中5907次有效、5097次弃权；有效严格错向2210次（有效反馈的37.4132%）。实际已问边中真实执行分数并列次数为0；保留并列方向的规则在代码中固定。原端点次序、弃权、置信度、汇总、评分和成本一并保持。

`run_2/` 是一次成功运行的原始封存产物，分析耗时约0.60秒，本机CPU，新增API/训练/GPU均0。潜在收益对应该固定赛程和现有执行标签；可实现学习裁判收益、理论上界、新任务和线上端到端结果各自需要后续证据。纠正后残余0.09814616由缺边、弃权与固定汇总等共同形成，其单独份额留待单因素对照。
