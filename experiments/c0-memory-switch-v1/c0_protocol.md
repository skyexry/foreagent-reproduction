# C0 replayability on archived sibling batches

Registered before computing recovery or memory-switch counts. Cohort and history availability were already known from chronological-memory-v1 at fbce9f7.

The estimand is the corrected tournament's top set on the ten observed candidates of each batch, fed the actual archived **parsed** judgments attached to their first ordered code pair and a maximum of 13 distinct feedback reads. The frozen C0 protocol compares at confidence 0.7 or higher. Work at the selection interface used by clean-ranking-v1. The historical original agent chose its own candidates, feedback and execution path. A reconstruction uses those recorded inputs conditionally. A historical rank, or a run under an arbitrary new revival seed, cannot by itself establish the C0 decision.

Match all 136 batches by run, first generation log line and full IDs in generation order. Check journal versus log decisions for normal and revival matches. Match first queries by prompt code identity, or by a uniquely determined ordered encounter and cache/miss evidence. At replay, remap cached winner identity under swapped presentation, enforce the distinct-read budget, and infer a revival opponent only when forced by the control flow or supported by the logged constraints. Multiple feasible opponents can yield the same output. A batch can be certified through a path-invariance argument, including the case where the complete remaining feedback is known to abstain after the read cap. A missing answer below the cap, ambiguous accepted outcome, or a changed future schedule without sufficient evidence is marked unresolved unless the result is invariant. Keep per-batch evidence and identify the first cause of unresolved paths. Record endpoint-labelled accepted edges only when their complete set can be certified. Retain original logged top sets and ranks for a separately labelled historical check.

The archived parsed interface and the raw-response parser are different evidence levels. Specifically, high-confidence coercions and missing winner fields in the original parser can be indistinguishable from genuine votes in the journal. Label exactness conditional on archived parsed records explicitly. No candidate training, API or GPU. Exclude validation/official scores and memory predictions from all reconstruction decisions. Run one registered analysis and preserve uncertain cases in the denominator.

Implementation notes. Tournament randomness is coupled to the historical sequence of revival draws, conditional on recorded choices. While the sequence lengths match, an observed opponent constrains the index in the corrected contender list. Once lengths differ the proof considers all remaining positions. First-query prompt blocks bind both program texts. Cache hits inherit the original recorded slot and confidence. For unlabelled revival opponents, filter choices by historical state, previously observed explicit first queries and cached slot/confidence. The full run’s first-query index checks for cross-batch cache entries. A previously unseen corrected edge is examined under all three possible responses (win on either side or abstain) to bound possible top groups and graphs. CPU exhaustive enumeration has a 10,000-node safety guard per batch. Duplicated program text violates the frozen selector's distinct-code precondition.

The field raw_parser_top_graph_certified is a sufficient certificate for all-abstention source batches. Historical journal entries store coerced indices and confidence. The old parser accepts inputs that the strict parser may reject. Raw exactness for the remaining accepted answers would need their typed original fields or a separate invariance proof. The field does not count those paths as raw-confirmed. The primary certified_parsed result is more widely observable. It holds the parsed judgment bank fixed and applies C0's orientation-correct cache, budget and tournament to those identities.
