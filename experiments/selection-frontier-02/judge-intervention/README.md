# 实际自适应C0上的局部裁判干预

**方向纠正D与弃权补证A均通过本轮oracle研究机会判据；二者在DeepSeek上的直接比较区间重叠。按预注册决策，保留C0，优先制作最小label-blind verifier原型，并以独立任务与实际成本比较验收。** GPT的D−A优势较清楚，DeepSeek差异仍有较大区间。

这是评价脚本掌握真实执行分数的oracle诊断：它说明这些模块存在可挖掘机会。后续可执行模型需要从代码、任务或原反馈作独立预测；本轮收益属于评价侧真值干预。

## 干预含义与实际成本

对每个task/无序pair，`int(sha256(UTF8(task + U+001F + canonical_pair)),16)%4`分配唯一fold。canonical pair为两个候选ID排序后用`|`连接。同地址跨银行和场次保持同fold；四个fold分别运行，任一模拟仅一个fold可改，资格分配沿用与结果无关的哈希。

- O：原C0完整实际路径。
- D：eligible且原C0 .7门槛已经采纳、真实存在严格优劣的pair中，纠正原错误方向，原confidence保留。原方向正确时保持原记录。
- A：eligible且原C0 .7门槛弃权、真实存在严格优劣的pair中，补真实胜者、confidence=.7。
- 实际同分pair、其余地址及其反馈按原记录保留。所有臂均重新执行实际配对、rematch、cache、早停和外部B cap，因此实际查询路径可以变化。
